# 📚 TuiLib (TUI E-Book Manager)

TuiLib is a lightweight, keyboard-centric terminal user interface (TUI) application for managing your digital library. It aims to provide a "Vim-like" experience 😎 for users who prefer staying in the terminal rather than using heavy GUI applications to manage their E-Book.

## Motivation

These personal project was intended to serve as a media to express use of programming language, file operation at OS level, system design and version control. The application is not optimise for efficient performance which might be added later on. Feel free to improve to suit personal purpose.
